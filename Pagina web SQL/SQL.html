SQL: guía rápida

Conceptos básicos para crear, cargar y consultar bases de datos.

1. Crear tablas

Una tabla almacena datos organizados en columnas y filas.

CREATE TABLE alumnos (
    id INT PRIMARY KEY,
    nombre VARCHAR(50),
    edad INT
);
PRIMARY KEY: identifica de forma única cada registro.

2. Insertar datos

Usamos INSERT INTO para agregar registros.

INSERT INTO alumnos (id, nombre, edad)
VALUES (1, 'Juan', 18);

También podemos insertar varios registros:

INSERT INTO alumnos (id, nombre, edad)
VALUES
(2, 'Ana', 19),
(3, 'Pedro', 20);

3. Mostrar datos

SELECT permite consultar los datos almacenados.

SELECT * FROM alumnos;
ID Nombre Edad
1 Juan 18
2 Ana 19
3 Pedro 20

4. Consultas típicas

SELECT nombre FROM alumnos;

Selecciona columnas específicas.

SELECT * FROM alumnos WHERE edad >= 18;

Filtra los resultados según una condición.

SELECT * FROM alumnos ORDER BY edad DESC;

Ordena los resultados.

UPDATE alumnos SET edad = 19 WHERE id = 1;

Modifica datos existentes.

DELETE FROM alumnos WHERE id = 1;

Elimina registros.

5. DER

Un Diagrama Entidad-Relación (DER) representa las tablas y cómo se relacionan entre sí.

ALUMNO
  • id_alumno (PK)
  • nombre
  • edad
1 ─── N
CURSO
  • id_curso (PK)
  • nombre
Un alumno puede estar relacionado con varios cursos. La relación 1:N significa "uno a muchos".
